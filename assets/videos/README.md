# 这是一个占位符文件
# 请将背景视频文件放置在此文件夹中

## 视频要求

- 文件名: background.mp4
- 格式: MP4 (H.264 编码)
- 分辨率: 1920x1080 或更高
- 时长: 10-30秒（会循环播放）
- 文件大小: 建议 < 10MB

## 视频优化建议

- 使用 HandBrake 等工具进行压缩
- 推荐码率: 2-5 Mbps
- 确保视频适合作为背景（不要太亮或对比度太高）

## 如果没有视频

如果暂时没有合适的视频，网站会自动使用渐变色背景作为备选方案。

更多详细说明请查看项目根目录的 MAINTENANCE.md 文档。
