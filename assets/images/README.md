# 这是一个占位符文件
# 请将您的个人照片/立绘放置在此文件夹中

## 建议的图片文件

- profile.jpg - 个人简介使用的头像或立绘
- costume-*.jpg - 各个皮套的展示图片
- gallery-*.jpg/png - 画廊作品图片
- emoji-*.png - 表情包图片（建议透明背景）

## 图片规格建议

- 个人头像/立绘: 1000x1000px 以上，PNG 格式
- 皮套展示图: 800x1200px，JPG/PNG 格式
- 画廊作品: 800x800px 或更高
- 表情包: 512x512px，PNG 格式

更多详细说明请查看项目根目录的 MAINTENANCE.md 文档。
