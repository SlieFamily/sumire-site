# 明日堇sumire 个人网站

虚拟主播明日堇sumire的个人展示网站，基于 Vite 构建的现代化静态网站。

## 技术特性

- 基于 Vite 8.3 的现代化构建系统
- ES Module 模块化架构
- 内容哈希文件名实现自动缓存失效
- 完整响应式设计，移动端优化
- 力导向布局算法（D3.js）实现人物关系网可视化
- 本地化字体资源（Inter、ZCOOL XiaoWei、Noto Serif SC）
- 纯静态部署，零后端依赖

## 页面结构

- **人物设堇** - 个人简介、电竞历程、人物关系网
- **千千堇听** - 歌曲列表，支持搜索和语言筛选
- **堇衣卫** - 历代皮套时间线展示
- **触堇生情** - 二创作品画廊（插画、表情包、漫画分类）
- **关于** - 网站说明
- **更新日志** - 版本更新记录

## 快速开始

查看 [QUICKSTART.md](QUICKSTART.md) 获取详细的开发和部署指南。

## 开发

```bash
# 安装依赖
npm install

# 启动开发服务器（端口 8000）
npm run dev

# 构建生产版本
npm run build

# 预览生产构建
npm run preview
```
