================================================================================
                        推送到 GitHub 的详细步骤
================================================================================

【第一步】在 GitHub 上创建仓库
────────────────────────────────────────────────────────────────────────
1. 打开浏览器，访问: https://github.com/new
2. 登录你的 GitHub 账号
3. 填写仓库信息:
   - Repository name: sumire-site
   - Description: 明日堇sumire的个人网站
   - 选择 Public (公开) 或 Private (私有)
   - ⚠️ 不要勾选 "Add a README file"
   - ⚠️ 不要选择 .gitignore 和 license
4. 点击绿色的 "Create repository" 按钮


【第二步】推送代码到 GitHub
────────────────────────────────────────────────────────────────────────
创建仓库后，GitHub 会显示一个页面，里面有推送命令。
在本项目文件夹中打开命令行（Git Bash 或终端），执行：

# 添加远程仓库（把下面的地址替换成你的）
git remote add origin https://github.com/你的用户名/sumire-site.git

# 确保分支名为 main
git branch -M main

# 推送代码
git push -u origin main

示例（如果你的 GitHub 用户名是 "zhangsan"）：
git remote add origin https://github.com/zhangsan/sumire-site.git
git branch -M main
git push -u origin main


【第三步】验证推送成功
────────────────────────────────────────────────────────────────────────
1. 刷新 GitHub 仓库页面
2. 你应该能看到所有的文件和文件夹
3. 查看 README.md 显示项目说明


【第四步】部署到 Vercel
────────────────────────────────────────────────────────────────────────
1. 访问 https://vercel.com
2. 点击右上角 "Sign Up" 或 "Log In"
3. 选择 "Continue with GitHub" 用 GitHub 账号登录
4. 授权 Vercel 访问你的 GitHub
5. 点击 "Add New..." → "Project"
6. 在列表中找到 "sumire-site" 仓库，点击 "Import"
7. 保持默认设置，直接点击 "Deploy"
8. 等待 2-3 分钟，部署完成！
9. 点击 "Visit" 或复制链接，查看你的网站


【常见问题】
────────────────────────────────────────────────────────────────────────
Q: 如果提示 "remote origin already exists"？
A: 先删除旧的远程仓库: git remote remove origin
   然后重新添加: git remote add origin <你的仓库地址>

Q: 推送时要求输入用户名和密码？
A: GitHub 已不支持密码登录，需要使用 Personal Access Token
   或配置 SSH Key。建议使用 GitHub Desktop 客户端更方便。

Q: 推送被拒绝 (rejected)？
A: 可能远程仓库有内容，使用: git push -u origin main --force
   （谨慎使用 --force）

Q: 部署后网站显示不正常？
A: 1. 检查浏览器控制台错误
   2. 确认 Vercel 部署成功（绿色勾号）
   3. 清除浏览器缓存后刷新


【更新网站】
────────────────────────────────────────────────────────────────────────
以后修改网站内容后，执行：

git add .
git commit -m "描述你的修改"
git push

Vercel 会自动检测到更新并重新部署。
